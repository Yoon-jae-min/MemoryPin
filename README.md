# 기억핀 (MemoryPin)

**버전 1.0.0** · `com.memorypin`

연결이 끊긴 순간, 휴대폰이 있던 위치를 자동으로 기억해 주는 Android 앱입니다.
이어폰·차량 블루투스 등 자주 쓰는 기기를 등록해 두면, 연결이 끊길 때 그 자리의 위치를 저장합니다.
(예: 차 블루투스가 끊기면 = 주차 위치)

## 핵심 개념

- **실시간 추적이 아닙니다.** "연결이 끊긴 순간 휴대폰이 있던 위치"를 한 번 저장합니다.
- 휴대폰에 **직접 연결되는 블루투스 기기**만 지원합니다. (지갑·열쇠 등은 별도 태그가 필요)
- 실내·지하주차장에서는 GPS 오차가 클 수 있습니다.

## 기능 (v1.0.0)

- **기기 등록**: 페어링된 블루투스 기기 중에서 추적할 기기를 고릅니다.
- **자동 위치 저장**: 등록한 기기의 연결이 끊기면 그 순간의 위치를 저장하고 알림을 표시합니다.
- **위치 보기**: 마지막 저장 위치를 좌표·주소로 확인하고, 지도 앱으로 열거나 길찾기를 실행합니다.
- **메모**: "B2 주차구역" 같은 메모를 위치에 남길 수 있습니다.
- **지금 위치로 저장**: 자동 저장을 놓쳤을 때 수동으로 현재 위치를 저장합니다.
- **일시중지**: 기기별로 자동 저장을 켜고 끌 수 있습니다.

## 확장 가능한 구조

연결 방식은 인터페이스로 추상화되어 있어, 블루투스 외 다른 방식도 쉽게 추가할 수 있습니다.

```
connection/
├─ SourceType.kt              # 연결 방식 종류 (BLUETOOTH / WIFI / BLE_TAG ...)
├─ ConnectionEvent.kt         # 통일된 연결 상태 이벤트 + 리스너
├─ ConnectionMonitor.kt       # 한 가지 연결 방식을 감시하는 공통 인터페이스
├─ BluetoothConnectionMonitor.kt  # 블루투스 구현체
└─ ConnectionManager.kt       # 여러 모니터를 모아 일괄 시작/중단
```

**새 연결 방식 추가 방법**

1. `SourceType` 에 항목 추가 (이미 `WIFI`, `BLE_TAG` 자리 마련됨)
2. `ConnectionMonitor` 를 구현한 클래스 작성 (예: `WifiConnectionMonitor`)
3. `ConnectionManager.registerDefaultMonitors()` 에 한 줄 등록

나머지 흐름(위치 저장·알림·UI)은 연결 방식과 무관하게 그대로 동작합니다.

## 권한

| 권한 | 용도 |
|------|------|
| 위치 (정밀/대략, 백그라운드) | 연결이 끊긴 순간의 위치 저장 |
| 근처 기기(블루투스) | 블루투스 연결/끊김 감지 |
| 알림 | 위치 저장 알림 |
| 포그라운드 서비스(위치) | 백그라운드에서 끊김 감지 |

## 빌드

- **Android Studio**: `MemoryPin` 폴더를 열고 Run.
- **명령줄(Windows)**: `gradlew.bat assembleDebug`

## 환경

- minSdk 24 · targetSdk 35 · compileSdk 35
- Kotlin + View Binding
- Material 3
- 저장: 내부 저장소 JSON (외부 DB 없음)
